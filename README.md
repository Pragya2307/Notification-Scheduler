# Notification Scheduler

A Java-based Notification Scheduler project developed using Data Structures and Algorithms.

## Features
- Schedule notifications for a specific date and time.
- Process notifications according to their scheduled time.
- Cancel pending notifications.
- Support recurring reminders.
- Save and load pending notifications using file handling.

## Data Structures Used
- Priority Queue
- Queue
- Circular Queue

## Technologies
- Java
- Java Collections Framework
- File Handling

## How to Run
1. Compile: `javac Main.java`
2. Run: `java Main`

## Project Files
- `Main.java` – Java source code.
- `Notification_Scheduler_Report.docx` – Project documentation.
